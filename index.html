Installateur Windows

Installe le jeu puis retrouve PITCHBOUND dans le menu Démarrer.

Installer PITCHBOUND ↗PITCHBOUND-Setup.exe

Archive portable

Extrais tout le contenu de l’archive dans un dossier, puis ouvre PITCHBOUND.exe.

Télécharger le ZIP ↗PITCHBOUND-Windows-x64.zip

L’installateur peut télécharger Microsoft WebView2 s’il manque. La version portable nécessite WebView2 déjà installé. Le jeu fonctionne ensuite hors ligne.

Cette pré-alpha n’est pas signée numériquement ; Windows peut afficher un avertissement de sécurité.

Les téléchargements sont accessibles sans compte GitHub.

Quelques repères avant de jouer

Ton premier pas.

  1. Installe ou extrais le jeu

    Choisis l’un des formats ci-dessus. Avec le ZIP, extrais tous les fichiers avant de lancer PITCHBOUND.exe.

  2. Crée ton joueur

    Découvre ses premiers souvenirs, puis rejoins son club à 14 ans. Le tableau de bord présente tes prochaines décisions ; l’aide du jeu explique les rubriques.

  3. Reprends ton histoire

    La progression est sauvegardée automatiquement. Une seule carrière est active à la fois : « Nouvelle carrière » remplace celle en cours après confirmation.

  4. Garde le fil lors d’une mise à jour

    Ferme le jeu avant d’installer une nouvelle version ou de remplacer l’exécutable. Rouvre-le puis reprends ta carrière.
