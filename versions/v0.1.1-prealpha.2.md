# PITCHBOUND — Archive de test 0.1.1-prealpha.2

Un jeu de **Drixx** · Jeu **0.1.1** · Windows 64 bits.

Cette révision concerne uniquement le paquet de test et sa présentation. Le jeu reste en version 0.1.1, avec le même contenu jouable jusqu’au bilan de la deuxième année universitaire à 18 ans. Les fichiers des publications précédentes sont conservés.

## Tester avec le ZIP portable

Télécharge **PITCHBOUND-Windows-x64.zip**, extrais **tout son contenu** dans un dossier, puis ouvre **PITCHBOUND.exe** depuis ce dossier. Microsoft WebView2 doit déjà être installé. Ne lance pas le jeu directement depuis le ZIP. Le jeu fonctionne ensuite hors ligne.

Les tests actuels utilisent uniquement ce ZIP. Un installateur signé est prévu ultérieurement. Cette pré-alpha n’est pas signée numériquement : Windows peut afficher un avertissement de sécurité, y compris pour un exécutable extrait d’un ZIP. Sur un PC professionnel, respecte les consignes de ton service informatique.

## Reprendre et faire un retour

Ferme le jeu avant de remplacer les fichiers par ceux d’une nouvelle archive extraite. Rouvre PITCHBOUND, puis choisis **Reprendre ma carrière** pour retrouver ton joueur. **Nouvelle carrière** remplace la carrière actuelle après confirmation.

Le ZIP contient **LISEZ-MOI.txt** et **THIRD-PARTY-NOTICES.txt**. **SHA256SUMS.txt** accompagne le téléchargement pour vérifier son empreinte. Pour un retour, indique la version visible dans **À propos**, la révision de l’archive (pré-alpha.2) et les étapes du problème, sur le formulaire public de ce dépôt ou directement à Drixx.
