# PITCHBOUND — Pré-alpha 0.1.1-prealpha.1

Un jeu de **Drixx** · Windows 64 bits.

Après le bilan de ta première année universitaire, poursuis dans ton club actuel et joue la deuxième année jusqu’à son bilan à 18 ans. Prépare ta saison, retrouve le championnat et fais avancer tes études ; tes acquis, tes relations et les obligations scolaires restent conservés. Le coach continue d’évaluer ta place dans le groupe.

Ferme le jeu avant la mise à jour, puis choisis **Reprendre ma carrière**. Depuis le bilan complet de première année, le bouton **Préparer ma deuxième année** ouvre la suite dans le même club. Une seule carrière reste active à la fois.

La troisième année à 19 ans, les transferts universitaires et les autres parcours ne sont pas encore jouables. Des bugs et des ajustements restent possibles.

- **PITCHBOUND-Setup.exe** : installateur Windows ; Microsoft WebView2 peut être téléchargé s’il manque.
- **PITCHBOUND-Windows-x64.zip** : extrais tout le contenu, puis ouvre PITCHBOUND.exe ; WebView2 doit déjà être installé.
- **LISEZ-MOI.txt**, **THIRD-PARTY-NOTICES.txt** et **SHA256SUMS.txt** accompagnent les téléchargements.

Le jeu fonctionne ensuite hors ligne. Cette pré-alpha n’est pas signée numériquement ; Windows peut afficher un avertissement. Pour un retour, indique la version visible dans **À propos** et les étapes du problème sur le formulaire public de ce dépôt, ou directement à Drixx.
